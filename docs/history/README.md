The `.original.txt` file preserves every byte, including the original relative
links. Its plain-text extension avoids presenting those links as working links
from this new directory. The readable `.md` version adds a historical banner
and changes only relative Markdown link destinations to immutable GitHub paths
at the source commit. Existing external links, prose and command examples are
unchanged. All 14 rewritten destinations exist at that commit.

`scripts/generate_audit.mjs` checks the original SHA-256 and the exact readable
transformation. The historical v0.9 PDF identity check now reads this original
archive; it still checks the actual configured PDF bytes independently. The
current README must retain its link to the readable archive.

The original four Palomar registrations, their files and evidence retain their
own identities. They are not requalified or reattributed by this documentation
change. Likewise, preserving the historical Halter–Koch discussion or the old
release-candidate text does not reopen its discharged mathematical premise or
assert a new qualified release. Later corrections, including the directional
Stein premise, remain in the [revision log](../PAPER_V3_REVISION_LOG.md) and the
[literature ledger](../../PaperCV282/LITERATURE_INPUTS.md).
